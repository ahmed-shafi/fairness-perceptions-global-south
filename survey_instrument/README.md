# Survey instrument materials

- **`english_survey_instrument.md`** — the canonical English wording for both the primary survey (ride-sharing, beauty-filter, and LLM scenarios, plus RQ4) and the supplementary ride-sharing-only follow-up survey. Reproduced from the manuscript's appendix.
- **`bangla_survey_instrument.pdf`** — the Bangla item wording, informed-consent text, and scenario vignettes, transcribed directly from the live Google Form (the underlying `survey.csv` export does not preserve this prose, only item-level question/answer labels). Contains no response data or participant identifiers.
- **`bangla_survey_instrument.tex`** — LaTeX source for the PDF above (compile with XeLaTeX; requires the Kalpurush font for Bengali script).

None of these files contain participant responses or identifying information. The live survey was administered bilingually, side by side in Bangla and English.
